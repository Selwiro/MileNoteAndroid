数据约定

01数据约定

四条约定，写在页面上，也写在代码里。

01

本地优先存储

账本写在应用私有目录下的单文件 JSON，原子写入；不经过开发者服务器。

02

无需注册账号

没有手机号、邮箱与第三方登录，打开即用；没有订阅，也没有广告。

03

满箱法口径透明

只统计两次「加满」之间，漏记就重设基准；综合油耗按里程加权，不猜也不补。

04

数据可完整带走

完整 JSON 备份包含全部车辆与自定义项，格式与 Web 版互通；费用可导出 CSV。

02为什么是里程志

不是又一个记账 App，
是一辆车的账本。

只记与车有关的支出，并把每一条口径写清楚：算不出来的指标显示「—」，不猜、不编。

账本的样子，应该像账本：有分类、有合计、有来龙去脉。

01

一车一本账

可添加任意数量车辆，费用、油耗、保养按当前车辆隔离。家庭两辆车，油费和保养不会混在一起。

完整 JSON 备份仍包含全部车辆。

02

满箱法油耗

第一次加满建立基准，未加满累计到下次结算，标记漏记就重设基准；综合油耗按里程加权，不用简单平均。

里程倒退或缺少里程的记录直接跳过。

03

保养先到为准

12 项默认保养方案，公里数或日期任一到期就进入待办；完成并记录后自动安排下一轮，首保后按实际日期与里程重算。

待办只在 App 内提示，不做系统通知。

05功能清单

一辆车需要的全部账目能力

该有的都有，不该发出去的也不发——所有计算与识别都在本机完成。

九类费用 + 自定义分类

油费、保险、保养、维修、汽车美容、过路费、停车费、罚单、汽车用品；可新增自定义分类，并参与筛选、图表与导入识别。

记一笔

分类图标网格置顶，金额、日期、里程与加油字段一屏填完；金额栏可直接拍照识别小票，保存前先核对。

拍照识别小票

CameraX 拍照或相册选图，ML Kit 中文端侧识别实付金额、加油量与日期；保守解析，不把优惠或单价当支出。

四通道导入

小熊油耗（XLS/XLSX）、钱迹、保养台账与 JSON 备份；字段映射、逐行预览、重复记录自动跳过，也能从系统分享直接导入。

费用统计

按月堆叠柱状图看支出趋势，环图看费用构成；点柱段或扇区弹出分类、金额与占比，统计与明细双页签。

油耗分析

两次加满之间算起，按里程加权；油耗走势、平均油费、每公里成本，今日油价含下次调价日期与方向。

保养计划

12 项默认方案表格化，日期在上、里程在下，按到期临近排序；完成即记录，单条提醒可导出 .ics 日历文件。

备份与导出

完整 JSON 备份与还原、当前车辆 CSV 导出；可选 WebDAV（坚果云 / Nextcloud / 群晖），密码加密保存，只在前台手动同步。

原生体验

Kotlin + Jetpack Compose + Material 3 Expressive；Photo Picker、SAF 文件选择、系统分享接收与粗略定位，权限只有四项。

本地优先

账本保存在应用私有目录下的单文件 JSON，车辆图片以 dataURL 内嵌，原子写入；不经过开发者服务器。

无需账号

不需要手机号、邮箱或第三方登录，打开即用；也没有订阅与广告。

随时带走

完整 JSON 备份包含全部车辆、记录、提醒与自定义项，格式与 Web 版互通；费用可导出 CSV。

08常见问题

你可能想问

需要注册账号吗？数据会上传吗？

不需要。账本默认只保存在本机，不经过开发者服务器；只有你在设置里主动配置 WebDAV 时，才会把账本同步到你填写的服务器。

换手机怎么迁移？

在旧设备导出完整 JSON 备份，在新设备恢复即可。备份格式与 Web 版同构（version: 2），Web → Android 已实测可恢复；也可以用 WebDAV 手动上传 / 下载。

为什么油耗和仪表盘表显不一样？

满箱法基于两次加满之间的实际加油量与里程差，和表显的瞬时/长期统计口径不同；路况、空调、载重与胎压也会影响结果。本工具只对录入数据负责。

保养到底按里程还是按时间？

按「先到为准」：公里数或日期任一到期就会进入待办。只填里程的项目不会推算日期，统一在保养计划表里管理。

支持电动车吗？

可以用自定义分类记录充电、保养与保险等支出；但满箱法油耗与今日油价面向燃油车，纯电车型没有电耗模型。

为什么没有系统通知提醒？

这是有意的取舍：不做后台常驻与通知权限，保养到期只在 App 内「待办事项」提示；需要时可以导出 .ics 日历文件到系统日历。

数据会不会丢？

账本采用原子写入，卸载应用前会提示导出备份；更换设备、清理数据前请先导出 JSON。已配置 WebDAV 的还可以从远端恢复。
