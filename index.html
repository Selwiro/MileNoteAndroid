里程志MileNote

一款简单实用的 Android 用车记账应用。支持多车管理、日常费用记录、油耗与电耗分析、保养计划和用车成本统计。

无需注册账号，数据默认保存在本地，也可以通过 WebDAV 在自己的设备之间同步。

功能介绍

  • 日常用车，轻松记录

    记录加油、充电、停车、保险、维修等各类用车支出。支持自定义分类、搜索筛选和小票识别，让日常记账更加方便。

  • 多辆车辆，独立管理

    支持添加多辆车辆，分别管理费用、能源消耗和保养记录。不同车辆的数据互不干扰，随时切换查看。

  • 油耗电耗，清晰掌握

    燃油车通过满箱法计算实际油耗，纯电动车通过满电法分析电耗。查看平均能耗、每公里能源费用和历史变化趋势。

  • 费用统计，一目了然

    自动汇总用车支出，通过月度趋势图和费用构成图，了解不同类型的花费，掌握长期用车成本。

  • 保养计划，及时查看

    根据日期和行驶里程管理保养项目，任一条件到期即进入待办。完成保养后，自动安排下一次计划。

  • 数据迁移，方便可靠

    支持导入小熊油耗、钱迹等应用的记录，提供 CSV 导出、完整 JSON 备份，以及可选的 WebDAV 同步。

界面预览

简洁直观的使用体验

基于 Material 3 Expressive 设计，提供五种主题配色、浅色与深色模式，以及中文和英文界面。

隐私与数据

数据默认保存在你的设备上

无广告、无订阅、无埋点统计。

WebDAV 同步需要自行配置存储服务，远端账本以明文 JSON 保存。

  • 无需账号不需要注册或登录。
  • 本地存储账本默认只保存在手机中。
  • 本地识别小票识别和文件解析均在设备端完成。
  • 自主备份随时导出完整账本，不依赖开发者服务器。
  • 可选同步使用自己的 WebDAV 服务管理跨设备数据。
