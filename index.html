里程志 MileNote 是一款简单实用的 Android 用车小助手：多车分开管，满箱法算真实油耗，保养到期提醒，用车成本一眼看清。

无需注册账号，数据默认保存在本机，也可以通过 WebDAV 在你自己的设备之间同步。

功能

日常用车，六件事都替你管

从记一笔到年度报告，全部在你的手机里完成，不联网也能用。

  • 日常用车，轻松记录

    加油、充电、停车、保养随手记，支持自定义分类与小票识别。

  • 多辆车辆，独立管理

    多车的费用、能耗与保养各自独立，随时切换查看。

  • 油耗电耗，清晰掌握

    满箱法 / 满电法算真实能耗，查看平均油耗与变化趋势。

  • 费用统计，一目了然

    自动汇总支出，月度趋势与费用构成看清用车成本。

  • 保养计划，及时查看

    按日期或里程到期提醒，完成后自动安排下一次。

  • 数据迁移，方便可靠

    导入小熊油耗、钱迹记录，支持 CSV / JSON 导出与 WebDAV 同步。

界面预览

简洁直观，用起来不费劲

基于 Material 3 Expressive 设计，五种主题配色、浅色与深色模式，中文与英文界面。

五种主题配色 浅色 / 深色模式 中文 / English 界面元素均支持大字号
隐私与数据

数据默认保存在
你的设备上

无广告、无订阅、无埋点统计。没有服务器在收集你的行车与加油记录。

WebDAV 同步需要自行配置存储服务，远端数据以明文 JSON 保存。

  • 无需账号不需要注册或登录。
  • 本地存储数据默认只保存在手机中。
  • 本地识别小票识别和文件解析均在设备端完成。
  • 自主备份随时导出完整备份，不依赖开发者服务器。
  • 可选同步使用自己的 WebDAV 服务管理跨设备数据，不经过任何中转。
